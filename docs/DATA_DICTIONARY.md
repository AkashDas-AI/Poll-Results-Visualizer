## 1. Primary Public Survey Schema (Stack Overflow 2025)

The primary dataset is stored as respondent-level wide format in `data/raw/stackoverflow_developer_survey_2025/survey_results_public.csv`. The accompanying dictionary is in `survey_results_schema.csv`.

### 1.1 Dataset Attributes & Target Populations
- **Dimensions:** 49,191 rows (respondents) $\times$ 172 columns (variables).
- **Target Populations:**
  - **Raw Extract ($N_{\text{raw}}$):** 49,191 unweighted records.
  - **Official Published Base ($N_{\text{official}}$):** 49,009 responses (182-row difference reflects internal qualification and completion time filters).
  - **Question-Specific Answered Counts ($N_{\text{answered}}$):** Varies per question due to conditional branching and skipping.
- **Primary Identifier:** `ResponseId` (unique integer 1 to 49,191, non-nullable).
- **Questionnaire Types:**
  - `RO` (49 items): Rank Order / Priority Rating.
  - `MC` (48 items): Multiple Choice (Single-select & Semicolon-delimited Multi-select).
  - `TE` (29 items): Text Entry / Numeric Input.
  - `Matrix` (13 items): Agreement Grid / Likert Scale.

### 1.3 Derived Analytical Variables (Phase 3 Cleaning Pipeline)

Generated by [`src/datasets/stackoverflow_cleaning.py`](../src/datasets/stackoverflow_cleaning.py) and stored in `data/processed/survey_results_cleaned.*`:

| Variable Name | Type | Source Variable | Description & Derivation Rule | Example Values |
| :--- | :--- | :--- | :--- | :--- |
| `YearsCode_num` | Float | `YearsCode` | Numeric coding experience in years. Floats $\ge 0.0$; `<1 year` mapped to `0.5`; `>50 years` mapped to `51.0`; null/unparseable to `NaN`. | `0.5`, `14.0`, `51.0` |
| `WorkExp_num` | Float | `WorkExp` | Numeric professional work experience in years. Floats $\ge 0.0$; `<1 year` mapped to `0.5`; `>50 years` mapped to `51.0`; null/unparseable to `NaN`. | `0.5`, `10.0`, `51.0` |

## 2. Standard Tidy Poll Schema (Dashboard Bridge)

To maintain compatibility with modular visualization components, the source adapter produces a standardized 5-column table (`build_poll_adapter_table`):

| Column Name | Data Type | Nullable | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `respondent_id` | `String` | No | Yes | Standardized identifier (e.g. `SO-10492`). |
| `question` | `String` | No | Yes | Standardized survey question prompt text. |
| `option` | `String` | No | Yes | Selected response option. |
| `response_date` | `Date` / `String`| Yes | Yes | Fieldwork date representation (Explicitly `None` for cross-sectional studies like SO 2025 where timestamps are omitted). |
| `segment` | `String` | Yes | Yes | Demographic cohort (e.g. `Age` group). |
